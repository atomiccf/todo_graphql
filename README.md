# 📌 todo_graphql_client

A full-stack **To-Do application** built with **GraphQL** and **React + Vite + TypeScript**.  
This project demonstrates how to use GraphQL queries and mutations to manage application state in a modern frontend setup.

---

## 🚀 Features

- Create, read, update, and delete to-do items (CRUD)
- GraphQL API for flexible and efficient data fetching
- Modern React frontend powered by Vite
- Type-safe codebase using TypeScript
- Clean and minimal project structure

---

## 🧱 Tech Stack

**Frontend**
- React
- Vite
- TypeScript
- GraphQL Client (Apollo / urql / graphql-request)

**Tooling**
- npm
- ESLint
- Prettier

---

## 📦 Installation

### 1. Clone the repository

```bash
git clone https://github.com/atomiccf/todo_graphql.git
cd todo_graphql
```
### 2. Install dependencies
```bash
npm install
```
### 3.Run the frontend
```bash
npm run dev
```
